# Discounting

## a1
What is the present value of €1,100 received in 1 year, with a discount rate of 10 %?

- [ ] €990
- [x] €1,000
- [ ] €1,010
- [ ] €1,210

Explication : present value = 1,100 / 1.10 = €1,000. €1,210 would be the value in 2 years of €1,000 invested at 10 %.

Source : Definition of discounting: C₀ = Cₙ / (1 + i)ⁿ

## a3
Discounting is the reverse operation of…

- [ ] amortisation
- [x] compounding
- [ ] allocation
- [ ] indexation

Explication : compounding carries a sum from today forward to a future date; discounting brings a future sum back to today.

Source : Definition of discounting: C₀ = Cₙ / (1 + i)ⁿ

## a4
All else being equal, if the discount rate goes up, the present value of a future sum…

- [ ] goes up
- [x] goes down
- [ ] stays the same
- [ ] becomes zero

Explication : the divisor (1 + i)ⁿ grows with i, so the quotient shrinks.

Source : Definition of discounting: C₀ = Cₙ / (1 + i)ⁿ

## a5
What is the present value of €5,000 received in 3 years, with a discount rate of 4 %?

- [ ] €4,464.29
- [ ] €4,807.69
- [x] €4,444.98
- [ ] €5,624.32

Explication : 5,000 / 1.04³ = 5,000 / 1.124864 ≈ €4,444.98. €5,624.32 is the accumulated value of €5,000 invested for 3 years at 4 %: that multiplies instead of dividing.

## a6
True or false: with a positive discount rate, €1,000 received in 5 years is worth more today than €1,000 received in 2 years.

- [x] False
- [ ] True

Ordre fixe : oui

Explication : the further away the sum, the bigger the factor (1 + i)ⁿ you divide it by. At 10 %, €1,000 in 2 years is worth €826.45 and in 5 years only €620.92.

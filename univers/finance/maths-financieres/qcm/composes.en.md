# Compound interest

## c1
Which formula gives the accumulated value after n years with compound interest, at annual rate i?

- [ ] C₀ × (1 + i × n)
- [x] C₀ × (1 + i)ⁿ
- [ ] C₀ × (1 + n)ⁱ
- [ ] C₀ / (1 + i)ⁿ

Explication : each year, the interest is added to the principal and earns interest in turn: you multiply by (1 + i) n times. The last formula is discounting.

Source : Definition of compounding: Cₙ = C₀ × (1 + i)ⁿ

## c2
You invest €1,000 at 5 % a year with compound interest for 2 years. What is the accumulated value?

- [ ] €1,100
- [x] €1,102.50
- [ ] €1,105
- [ ] €1,125

Explication : 1,000 × 1.05² = 1,000 × 1.1025 = €1,102.50. €1,100 would be the value with simple interest.

Source : Definition of compounding: Cₙ = C₀ × (1 + i)ⁿ

## c4
Same principal, same annual rate, term of 5 years. Compared with simple interest, compound interest gives…

- [ ] the same accumulated value
- [ ] a lower accumulated value
- [x] a higher accumulated value
- [ ] a value that depends on the principal only

Explication : for n > 1 and i > 0, (1 + i)ⁿ > 1 + i × n. Interest from past years earns interest itself.

Source : Comparison of (1 + i)ⁿ and 1 + i × n for n > 1 and i > 0

## c5
A half-yearly rate of 10 % is equivalent to which annual rate, with compound interest?

- [ ] 20 %
- [x] 21 %
- [ ] 22 %
- [ ] 10.5 %

Explication : (1 + 0.10)² = 1.21, or 21 % a year. It is not 20 %: the first half-year's interest earns interest in the second.

Source : Definition of the equivalent rate: (1 + annual i) = (1 + half-yearly i)²

## c6
Match each quantity to its formula.
Type : associer

- Simple interest = C × i × n
- Accumulated value with simple interest = C₀ × (1 + i × n)
- Accumulated value with compound interest = C₀ × (1 + i)ⁿ
- Present value = Cₙ / (1 + i)ⁿ

Explication : simple interest is proportional to time. With compound interest, you multiply by (1 + i) n times. Discounting divides instead of multiplying.

## c7
Put the steps for calculating an accumulated value with compound interest in order.
Type : ordonner

1. Note the starting principal, the annual rate and the term in years.
2. Calculate the factor 1 + i.
3. Raise this factor to the power n.
4. Multiply the result by the starting principal.
5. Subtract the principal to isolate the interest.

Explication : first you build the multiplying factor (1 + i)ⁿ, then you apply it to the principal. The interest is only calculated at the end, by difference.

Introduction : An investment earns interest: the price of lending money. With simple interest, it is always calculated on the starting principal. It is the basic building block before compound interest and discounting.

## The principle of simple interest
### Interest always calculated on the same principal
Each period, the interest earns the same amount, because it applies only to the principal invested at the start. Interest already paid earns nothing. It therefore grows steadily over time.

::: definition Simple interest
A sum paid in return for lending a principal, proportional to the principal, the rate and the time.
:::

::: formule
I = C × i × n
:::

- **C**: principal invested, in euros.
- **i**: annual interest rate, written as a decimal (5 % = 0.05).
- **n**: term, in years.

::: attention The rate and the term must refer to the same period
An annual rate goes with a term in years. For 6 months, n = 0.5.
:::

## From interest to accumulated value
### Principal plus interest
The accumulated value is what you get back at the end of the investment: the starting principal plus the interest.

::: formule
Accumulated value = C + I = C × (1 + i × n)
:::

::: exemple €2,500 at 3 % for 4 years
- Interest: I = 2,500 × 0.03 × 4 = €300.
- Accumulated value: 2,500 + 300 = €2,800.
:::

::: cascade From principal to accumulated value
+ Principal invested | 2 500
+ Interest over 4 years at 3 % | 300
= Accumulated value | 2 800
Unité : €
Note : each year's interest is identical, €75 a year.
:::

### Finding an unknown
The formula reads both ways. For the rate: i = I / (C × n). For the term: n = I / (C × i). Example: €48 of interest on €800 in 1 year gives i = 48 / 800 = 6 %.

## Reading how interest grows
Interest is proportional to time: if n doubles, I doubles. It is also proportional to the principal and the rate. The graph of the accumulated value against time is therefore a straight line.

## À retenir
- Simple interest: I = C × i × n.
- The principal that earns interest stays the starting one.
- Accumulated value = C × (1 + i × n).
- Interest is proportional to the term, the principal and the rate.
- Write the rate as a decimal: 5 % = 0.05.
- Rate and term must use the same unit of time.
- Interest is not the accumulated value: you must add the principal.

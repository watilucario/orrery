# Spaced repetition

## e1
What does the spacing effect say?

- [ ] Reviewing once is enough if the session is long
- [ ] The more you reread in one go, the longer you remember
- [x] Reviews spread over time are remembered better
- [ ] You must wait until you have forgotten everything

Explication : for the same total time, spreading out reviews gives a more durable memory than packing them together. Waiting until you have forgotten everything is too late.

## e2
Studying 3 hours in one go the night before gives the same lasting memory as 1 hour a day for three days.

- [ ] True
- [x] False

Ordre fixe : oui

Explication : cramming works in the short term, but the memory fades quickly. The same hours spread out leave a longer-lasting trace.

Type : trous

## e4
A card has a stability of 4 days. Match each delay with its probability of recall (form from the course sheet).

Type : associer

- 4 days = 90.0%
- 8 days = 82.5%
- 12 days = 76.6%
- 16 days = 71.8%

Explication : R = (1 + 19/81 × t/4)^(−0.5). The ratio t/S is 1, 2, 3, then 4.

Type : ordonner

3. FSRS recomputes difficulty and stability

Explication : your rating feeds the calculation. The date follows from the new stability.

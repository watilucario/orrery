# Active recall

## r1
What is active recall?

- [ ] Rereading your notes aloud several times
- [ ] Highlighting the key ideas in your course
- [ ] Neatly copying out the summary sheet
- [x] Retrieving an answer without looking

Explication : you produce the answer yourself, then check it. Rereading, highlighting and copying do not require you to retrieve anything.

## r2
Rereading your notes several times is an effective way to study.

- [ ] True
- [x] False

Ordre fixe : oui

Explication : rereading gives a feeling of familiarity, not a memory that lasts. Testing yourself makes your memory work harder.

## r3
The ___ effect: retrieving something from memory helps you keep it longer than rereading.

Type : trous

- [x] testing

Explication : the testing effect, described notably by Roediger and Karpicke (2006), shows that retrieving a memory strengthens it.

Source : Course sheet · recall

## r4
Match each situation with what it tells you.

Type : associer

- Right and sure = Solid knowledge
- Right but unsure = Fragile memory to strengthen
- Wrong and sure = False certainty to fix quickly
- Wrong and unsure = A gap you already know about

Explication : combining the result with your confidence tells you what to do next. That is the point of the "Are you sure?" question in the app.

## r5
You were sure of your answer, but it is wrong. Why does this case matter?

- [ ] It shows that you are unlucky
- [ ] It proves that the question was badly worded
- [x] It reveals a false certainty to fix
- [ ] It adds nothing: a mistake is a mistake

Explication : a mistake made with confidence is one you would not spot on your own. Correcting it right away is therefore very valuable.

## r6
> I reread my course three times in a row.
> The text feels more and more familiar.
> This familiarity proves I could retrieve it without help.
> So I move on to another chapter without testing myself.

Which step is wrong?

- [ ] I reread my course three times in a row.
- [ ] The text feels more and more familiar.
- [x] This familiarity proves I could retrieve it without help.
- [ ] So I move on to another chapter without testing myself.

Niveau : expliquer

Explication : recognizing a text is not the same as being able to retrieve it. This is the illusion of knowing: only a test reveals it.

## r7
Put a good active recall sequence in order.

Type : ordonner

1. Read the question
2. Try to answer from memory
3. Give your confidence
4. Look at the correction
5. Note whether you were right

Explication : you answer before seeing the correction. You give your confidence beforehand, otherwise it is distorted.

Source : Course sheet · recall

## r8
It is better to avoid testing yourself until you are ready, so as not to make mistakes.

- [x] False
- [ ] True

Ordre fixe : oui

Explication : a test reveals your gaps and strengthens what you retrieve. A mistake corrected quickly helps you remember.
